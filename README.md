# 🔐 GET & POST Request – Login Form

A beginner-friendly full-stack project demonstrating how **GET and POST HTTP requests** work between a frontend login form and a backend server.

The project focuses on understanding how form data such as a username and password is sent from the frontend to the backend and handled by the server.

## 🚀 Features

- Login form with username and password
- Frontend and backend separation
- GET request handling
- POST request handling
- Form data submission
- Backend request handling
- Understanding `req.body`
- Basic client-server communication

## 🛠️ Technologies Used

- **HTML5** – Login form and frontend structure
- **CSS3** – Styling
- **JavaScript** – Client-side functionality
- **Node.js** – Backend runtime
- **Express.js** – Server and routing
